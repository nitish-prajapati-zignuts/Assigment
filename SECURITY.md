# Security Policy

## Project Description

The **AI-Powered Meeting Notes & Action Item Summarizer** is a full-stack, enterprise-grade web application designed to capture, structure, summarize, and extract actionable insights from meeting transcripts using AI.

## Supported Versions

We are committed to securing this application. We actively support and patch the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do **not** open a public issue. Instead, report it privately to ensure the security of our users.

### How to Report
Please send an email to **security@zignuts.com** with the following details:
- **Description of the vulnerability**: A detailed explanation of the issue.
- **Steps to reproduce**: Code, commands, or proof of concept steps showing how to exploit it.
- **Potential Impact**: What could a malicious actor achieve?

### What to Expect
- **Response Time**: We will acknowledge your report within 48 hours.
- **Triage & Patching**: We will keep you updated as we work on a fix.
- **Disclosure**: We will coordinate the public announcement release notes after the patch is deployed.
